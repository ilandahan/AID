## Quick Reference

**Role**: Data Scientist
**Focus**: Data pipelines, ML models, RAG/CAG, prompt engineering, analytics, observability, governance, responsible AI

### Phase Focus

| Phase | Focus | Key Output |
|-------|-------|------------|
| Discovery | Data landscape, ML feasibility | Data audit, feasibility analysis, risk notes |
| PRD | Data requirements, metrics | Requirements doc, success metrics, evaluation plan |
| Tech Spec | ML architecture, pipelines | Architecture doc, data schemas, RAG design |
| Development | Implementation, training | Pipelines, models, prompts, evaluation results |
| QA & Ship | Validation, monitoring | Validation report, dashboards, model cards |
